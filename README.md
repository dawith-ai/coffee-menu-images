# coffee-menu-images — 커피 메뉴 이미지 저장소

커피 주문 앱이 메뉴를 그릴 때 쓰는 음료 이미지를 제공한다.

## 주요 기능

- 음료 이미지 26종 제공 — 커피·라떼·에이드·티·프라페·요거트 전 카테고리
- 파일명이 곧 메뉴 키 — `Lemonade.png`처럼 메뉴 이름으로 저장해 앱에서 이름만으로 바로 참조한다
- 커피 계열 — 아메리카노 · 디카페인 아메리카노 · 카페라떼 · 디카페인 라떼 · 콜드브루 · 콜드브루라떼 · 카라멜마키아토 · 연유라떼 · 꿀커피 · 커피프라페 · 자바칩프라페 · 바닐라라떼 · 토피넛라떼
- 논커피 계열 — 초코라떼 · 민트초코라떼 · 그린티라떼 · 딸기라떼 · 버블밀크티
- 에이드·티 — 자몽에이드 · 청포도에이드 · 레모네이드 · 복숭아티 · 유자티 · 아이스티샷추가
- 요거트 — 플레인요거트 · 딸기요거트
- GitHub raw URL로 바로 참조 — 앱에 이미지를 번들하지 않고 원격에서 불러온다
